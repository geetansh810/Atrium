**State: FIRST REAL AGENT LIVE (M0.5a+M0.5b done, 2026-07-13 session 6c).** `execution/spi/` verbatim 13 §1.1 (LlmMessage/ToolDef/ToolCall/Request/Result records, LlmProvider/LlmClient interfaces, LlmException w/ 7-kind taxonomy). `LlmRouter implements LlmClient`: provider bean map, catalog validation via registry's `ModelCatalogLookup`, Future-based timeout (`atrium.llm.timeout` 120s), in-attempt retries (RATE_LIMITED 3× / PROVIDER_DOWN 2×). `AnthropicClient` on official SDK `com.anthropic:anthropic-java:2.34.0` (maxRetries 0; missing key → AUTH; refusal → CONTENT_FILTERED; also implements new `ProviderReadiness.isReady()` — deliberately NOT on the frozen LlmProvider SPI — for the pre-dispatch gate). `LlmCostCalculator` (µUSD from catalog prices). **M0.5b: `LlmLoopRuntime implements AgentRuntime`** — replaces the M0.2 descriptor placeholder; one **virtual thread** per active agent (⚠️ forced a Java 17→21 bump, see below), `runOnce(companyId, agentId)` runs 13 §3.2 steps 0–7 and is public so tests drive it deterministically instead of racing the poll timer: 0 pre-dispatch gate (unready provider → park, log, skip tick, never claim), 1 `WorkBroker.claimNext` by skill set, maxAttemptsPerTask pre-check (flag `max_attempts` before any LLM spend), 2–3 `PromptAssembler.build(roleDef, task, feedback=null, bundle=null)` (pure — 05 rule; feedback wiring is M0.6, bundle is M-CTX1), 4 `llmClient.complete` (empty tools list — no tool-loop yet, nothing can hallucinate tool_use), 5–6/7 `UsageRecorder.record` + `TaskService.complete` in **one explicit `TransactionTemplate` tx** (MANDATORY-propagation UsageRecorder joins it) — failure path flags via `FlagReasons` (13 §1.3 kind → reason string), never crashes the loop. `AgentLifecycleService` (registry) start/stop wired to hire/pause/unpause. **Deliberately deferred:** tool-calling loop, periodic lease renewal during long calls, ContextAssembler (bundle always null), M0.6 feedback wiring, M0.7 budget auto-pause trigger. **⚠️ Java bump 17→21:** 12 §8/13 §3.2 assume virtual threads (`Thread.ofVirtual()`, Java 21+) but 08-conventions.md pinned 17 — a real contract gap, resolved docs-first by bumping `java.version` (pom.xml, both Dockerfile stages, 08-conventions.md, CLAUDE.md) to 21 LTS.

**Key rules:**
- `PromptAssembler.build(roleDef, task, feedback?)` is a **pure function that only sees those three inputs** — secrets structurally impossible in prompts. Rejection feedback included on retry (M0.6).
- Every LLM call → `usage_records` insert with idempotency key `taskId:attempt` in the same tx ([[accountability]]) — redelivery never double-bills.
- Provider failure → `TaskService.flag()`, never crash the runner. Completion → artifact row + `pending_review`.
- API keys from env only, never logged.
