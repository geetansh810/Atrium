# Third-party licenses

Atrium is built on the open-source libraries below. This list is a hand
audit of this repo's own direct dependency declarations (`core-api/pom.xml`,
`web/package.json`) as of M3.5 (2026-07-17) — **not** generated by an
automated license scanner, and does not enumerate every transitive
dependency each of these pulls in. Before a real commercial launch, replace
this with the output of a real tool (`license-maven-plugin` for the Java
side, `license-checker` for npm) run against the full resolved dependency
tree, not just the direct declarations below.

The former vendored SkyOffice/LimeZu pixel-art assets — the one dependency
that ever needed a paid-license launch-blocker check (06 §D) — were removed
entirely when the office track retired (2026-07-15, `07-milestones.md`
M2.4a–c). Nothing in the current codebase carries that obligation anymore.

No Stripe or other payment-processor SDK is a dependency — billing (M3.3) is
deferred post-pilot (07 Rev D) and has never been added.

## Frontend (`web/`, bundled into the shipped static build)

Only `dependencies` in `package.json` end up in the built bundle —
`devDependencies` (TypeScript, Vite, oxlint, `@vitejs/plugin-react`, `@types/*`)
are build-time tooling only and ship nothing to a user's browser.
